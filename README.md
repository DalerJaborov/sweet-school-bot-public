# Sweet School Bot

Автоответчик и воронки для Instagram онлайн-школы кондитерского мастерства.
Замена ManyChat: кнопки, цепочки сообщений с паузами, видео, метки «уже проходил» —
плюс ИИ-консультант (Gemini), который отвечает на свободные вопросы.

## Устройство

```
apps/api   Express + Prisma (SQLite) — вебхуки Instagram, движок воронок, ИИ, панель-API
apps/web   React + Vite — панель управления: Воронки / Журнал / Настройки
```

## Запуск

```bash
npm install
cp apps/api/.env.example apps/api/.env   # заполнить JWT_SECRET и ADMIN_PASSWORD
npm run prisma:migrate --workspace=apps/api
npm run dev:api    # http://localhost:4100
npm run dev:web    # http://localhost:5180
```

## Как работает воронка

- Триггер «С комментария»: человек комментирует публикацию (по ключевому слову или любой
  комментарий) → первый шаг уходит private reply в директ.
- Триггер «Из директа»: человек написал первым → стартует цепочка приветствия.
- Шаг с кнопками ставит цепочку на паузу; каждая кнопка ведёт на номер шага (ветка).
- Шаг без кнопок отправляется сам после паузы (`delaySeconds`), фоновый разносчик
  проверяет расписание раз в 10 секунд и переживает перезапуск сервера.
- «Конец ветки» (stopAfter) завершает цепочку, чтобы ветка «АРТ-десерт» не переползла
  в ветку «21 рецепт».
- Повторной выдачи нет: уникальность «воронка + человек» в базе + метка (тег) на карточке.
- Сообщение, которое не поймала ни одна воронка и не кнопка, отдаётся ИИ-консультанту
  (если включён в Настройках). Ошибка ИИ = тишина клиенту и запись в лог, не мусор в директ.

## Подключение Instagram (когда дойдут руки)

1. Приложение в developers.facebook.com с продуктом Instagram → API setup with Instagram login.
2. Маркер доступа аккаунта школы → в панель, Настройки → «Маркер доступа Instagram».
3. Вебхук: адрес `https://<домен>/webhooks/instagram`, проверочное слово — то же, что в
   Настройках («Проверочное слово вебхука»); подписаться на `messages` и `comments`.
4. «Секрет приложения Meta» в Настройках включает проверку подписи вебхука (рекомендуется).
5. Если хостинг не достукивается до graph.instagram.com напрямую — прописать прокси в
   `IG_PROXY_BASE` в `.env`.

## Ограничения Meta (это не баги)

- Ответить человеку можно в течение 24 часов после его последнего сообщения —
  паузы в цепочке должны укладываться в это окно (у ManyChat правило то же).
- Кнопок до 3 в нашей панели (Meta позволяет до 13), надпись кнопки ≤ 20 символов.
- Кнопки рисует сам Instagram — выглядят ровно как в ManyChat.
