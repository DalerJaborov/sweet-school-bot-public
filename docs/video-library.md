# Библиотека видео для клиентов (бот)

Код: `apps/api/src/ai/videoLibrary.ts`, вызов — `apps/api/src/ai.ts` (после меню, до одобренных примеров).

## Что делает
- Явная просьба показать («покажите видео вупи пай», «как выглядит …») — бот шлёт ролик ВМЕСТО ответа модели.
- Просто упомянули десерт («есть десерт с вупи пай?») — ролик уходит ВДОБАВОК, ответ даёт модель.
- «Покажите видео/примеры» без названия — подборка роликов-десертов, не больше 3 (если в списке их меньше трёх, подборки нет).
- Не понимают, что такое онлайн-курс («как проходит онлайн», «что такое онлайн», «как смотреть уроки») — ролик «как смотреть онлайн-урок» (запись kind howto). Про офлайн-курс не срабатывает.
- Слова ищутся ЦЕЛЫМИ («например» не считается за «пример»). Про деньги, оплату, реквизиты, перевод, чек, карту, цену, «сколько» — ролик не шлётся вообще: модель отвечает по делу.
- Сообщение с вложением (чек, фото, голос) — не просьба про видео. Купившей курс ролики не шлём.
- Видео и подпись уходят ОДНИМ сообщением (у WhatsApp-моста лимит 8 отправок за 10 минут на чат); перед отправкой считается остаток лимита, одна отправка оставляется под ответ бота.
- Не больше одного показа каждого вида за разговор.
- Подпись не содержит цен, просьб об оплате, смайликов и слова «школа» — такая запись отбрасывается.

## Настройки (панель → Ещё → Для опытных → Настройки → «Видео для клиентов»; ключи)
- `videoLibraryEnabled` — рубильник, `true` включает. **По умолчанию выключено.**
- `videoLibrary` — JSON-список. Пусто — используются два реальных превью уроков с сайта (Вупи пай, Лимон и манго).

```json
[
  {
    "id": "rafaello",
    "kind": "dessert",
    "dessert": "Рафаэлло",
    "keywords": ["рафаэл"],
    "url": "https://shirinsweets.online/video/rafaello.mp4",
    "caption": { "ru": "Вот как выглядит Рафаэлло", "tg": "Ин Рафаэлло аст" }
  },
  {
    "id": "howto",
    "kind": "howto",
    "url": "https://shirinsweets.online/video/kak-smotret-urok.mp4",
    "caption": { "ru": "Вот как проходит онлайн-урок", "tg": "Дарси онлайн ингуна мегузарад" }
  }
]
```

Требования к файлам: mp4 до 8 МБ (лимит моста WhatsApp). Адрес — только путь на сайте /img/…/x.mp4 или /video/…/x.mp4 либо https-ссылка на тот же путь на нашем сайте (shirinsweets.online); пути /api, чужие хосты, http — отбрасываются. Названия десертов на таджикском остаются русскими.

## Какие ролики реально есть (на 08.11.2026)
- В репозитории: только `apps/web/public/img/lessons/whoopie-preview.mp4` (Вупи пай, 8 с) и `mango-preview.mp4` (Лимон и манго, 7 с) — это превью уроков, показывают процесс, а не готовый десерт.
- Уроки курса на сервере хранятся зашифрованным HLS — для отправки клиентам нужны отдельные нарезанные клипы (не сделаны).
- Ролики готовых десертов и запись экрана «как смотреть онлайн-урок» — у владельца (Telegram), в репозитории их нет. Нужно прислать файлы; тогда их кладут на сайт и вносят в `videoLibrary`.

## Баннеры
`node apps/web/scripts/render-promo-banners.mjs` → `apps/web/public/img/banners/banner-{online-70,online-50,offline}-{ru,tg}.jpg` (1080×1350). Тексты — из `site-content`, фото — из `public/img/desserts`; цен и дат на баннерах нет.

## Проверка на живом номере
Перед включением на проде: отправить пробный ролик на тестовый номер и убедиться, что мост (Chromium) доставляет видео с подписью. Автотестами это не проверяется.
