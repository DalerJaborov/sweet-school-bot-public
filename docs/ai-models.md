## Факты и оговорки
- ФАКТ: gemini-3.7-flash, 3.6-flash, 3.8-flash, 3.5-flash(-lite), 3.1-flash-lite отвечают на нашем ключе; `gemini-3.1-flash` — 404.
- ФАКТ: на странице цен нет gemini-3.7-flash и 3.5-flash; в `ai/pricing.ts` для них взята ставка 3.6 (ОЦЕНКА).
- ФАКТ: прежние ставки в `pricing.ts` для 3.6-flash (0.3/2.5) были занижены в 2,5 раза — отчёты о расходах недооценивали траты. Исправлено.
- Реальные траты (журнал AiLog, по старым ставкам): ответы ≈ $0.59, уроки ≈ $0.26, всё вместе около $1; по новым ставкам около $2,3. Деньги не главная проблема — главная: ответ не должен подставить хозяйку.

## Экономичная схема (не ломает качество)
1. Дешёвая flash-lite — фильтр и расшифровка для фильтра. Уже сделано.
2. Основной ответ — flash (3.6), как сейчас. Не понижать: он держит правила и стиль.
3. Pro — только где качество решает: транскрипция уроков. Для голосовых клиентов оставить, пока нет замера на живых записях.
Всё меняется настройками без пересборки: `aiModel`, `aiModelVoice`, `aiModelGate`, `aiModelGateStt`; выключатели `replyGateEnabled`, `reactionsEnabled`.
