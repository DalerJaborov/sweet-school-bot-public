# Значок и предпросмотр ссылок

Единый знак кекса Shirin Sweets: SVG, ICO 16/32/48, Apple 180, PWA 192/512 и отдельный безопасный maskable. Знак сохранён по мотиву существующей иконки, палитра берётся из tokens.css.

18 изображений RU/TG для девяти страниц, 1200×630 JPEG. Использованы реальные фотографии уже опубликованных материалов lessonSamples. Заголовки взяты из существующего h1, новых обещаний нет. Добавлены alt, Twitter title/description и версия адресов для обновления кеша. Canonical, hreflang, title/description и noindex личных приложений сохранены.

Проверка: 354 теста интерфейса, размеры и наличие всех картинок, ICO и иконки, SEO generated/dist, полная сборка. Кадры примеров: D:/design-ref/shots/school-refinement-20261108/brand-sharing/.

Предпросмотр зависит от кеша мессенджера и поисковика; изменение не гарантирует мгновенное обновление уже отправленных ссылок. Реальные публикации в мессенджеры для проверки не отправлялись.
