# Мобильный интерфейс и покупка — 08.11.2026

Сохранён согласованный внешний вид. Исправлены воспроизведённые дефекты, без смены стиля.

- Покупка в React и серверном каталоге открывает существующий чат с выбранным курсом и актуальной ценой в черновике. Сообщение отправляется только действием посетителя. При паузе, отсутствии JavaScript или недоступности чата остаётся рабочая ссылка WhatsApp.
- Исправлено чтение `data-chat`: прежний обработчик искал другой атрибут и терял выбранный курс. Запрос открытия сохраняется до подключения ленивого виджета.
- Меню закрывается Escape и возвращает фокус. Чат сначала фокусирует диалог, после загрузки — поле, если посетитель ещё не выбрал другой элемент. Отправка оставляет фокус в поле, сохраняет следующий набранный черновик и корректно очищает отправленный текст с пробелами.
- Чат использует общие цветовые токены и шрифт с таджикскими буквами, поддерживает тёмную тему. Поле ввода 16px, основные цели касания минимум44px, фокус вложения видим. Учитываются безопасные зоны и уменьшение движения.
- Контакты доступны из шапки на компьютере и нижней панели на телефоне: звонок, WhatsApp, Telegram, Instagram. Тёмная тема не теряет контраст текста комплекта.
- В кабинете длинные имена и названия не расширяют экран. На320px прогресс курса расположен под описанием. Текст качества видео не переносится внутри кнопки; ряд элементов управления может занимать две строки.
- Заголовки ошибок локализованы по причине, неизвестная ошибка не показывает технический текст сервера. В карточках и первом экране урока используется исходное фото, затем прежняя обложка как запасной вариант. Файлы, рецепты, видео и подготовленные картинки для отправки не переписывались.

Движение учитывает [Apple HIG](https://developer.apple.com/design/human-interface-guidelines/motion). «Тренд ноября» не использован как повод менять одобренный стиль или ухудшать скорость.
